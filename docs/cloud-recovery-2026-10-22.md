# 2026-10-22 云端 HTTP 500 故障修复

用户截图显示硅基流动转写接口返回 HTTP 500。原实现一次请求失败后立即报错；这是服务端返回的错误，并非 API Key 输入框未保存。截图没有服务端请求标识，无法追溯该次请求的内部原因。

## 修复

- 对 HTTP 500、502、503、504，等待 1 秒／2 秒后重试，总共最多 3 次请求。每次重新打开完整录音，避免重试上传空流；每次上传前保留免费价格核验。显示重试进度，取消后不再上传。
- 401／402／403／429 等错误不自动重试、不更换收费模型、不自动加载本地模型。持续故障时仍由用户选择重试或本地识别。
- 空 WAV 或损坏／不支持的录音提前报错，不再上传给云端。当前仅支持软件录制的 16kHz 单声道 PCM16 WAV。
- 修复失败状态退出软件会删除暂存录音的问题；失败录音仍按原有最长 24 小时清理策略保留，明确丢弃或取消则删除。
- 云端／本地手动重试继承原编辑器身份。成功后点回原编辑器即可沿用直接填入流程，不强制切换到其他输入框，不自动发送。

- `72 passed`，覆盖完整重传、重试上限、重试取消、价格变化阻止重传、非临时错误不重试、空／损坏录音、退出保留与明确丢弃、重试的原编辑器身份保留。
- 使用 Windows 离线语音生成固定中文短句，音频长约 5.15 秒。通过软件现有免费价格保护后，以原有密钥实际调用 `FunAudioLLM/SenseVoiceSmall` 成功，约 2.05 秒完成，返回文本与固定短句一致。证据：本机忽略目录 `data/cloud-recovery-test/cloud.json`。没有使用麦克风或用户录音，没有发送任何 Agent 消息；不能由此推断真实口述准确率达标或服务长期稳定。
- 新版 EXE 已重建，并检查内嵌模块确实包含最新重试实现。最终打包版在隔离配置中启动、截图、退出通过，退出码 0，无界面回调错误；空闲私有内存约 51～52 MB，没有本地模型子进程。证据：`data/package-preview-test/gui.json`。更新前正常关闭旧程序并备份／恢复暂存文件，未变更用户密钥、识别模式或历史文字。
