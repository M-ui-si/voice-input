# 2026-10-22 侧边收起

## 操作

- 悬浮条右侧“收起”将主条缩为 22 × 56 像素箭头，贴到当前显示器工作区的较近左／右边缘。菜单可指定边缘。
- 点击箭头只展开，不开始录音。拖动箭头调整位置或换边；拖动和点击区分处理。展开为原有 286 × 78 主条，仍在当前工作区内。
- 收起时隐藏实时预览，并缓存最新文字；展开后继续显示。收起、换边、拖动不取消或重建识别任务。
- 快捷键仍可录音和停止；录音状态有红点。收起时识别错误不自动弹窗；展开后通过原有结果入口查看。
- `collapsed`、`dock_side` 与实际 Win32 坐标保存到设置。旧设置默认展开，异常字段回退默认值；支持负坐标和显示器工作区夹取。

## 生命周期

收起／展开复用同一 Win32 主窗口及快捷键注册，不创建额外的置顶手柄窗口。窗口尺寸和监视器坐标采用 Win32 实际值，主条和预览继续使用不激活样式。

桌面探针曾在原生 WM_HOTKEY 回调内执行 Tk `after` 时触发 Python 3.14 的 GIL 状态异常。现回调只排队，Tk 每 25 ms 检查并执行；退出时取消该轮询及界面 tick，避免原生回调重入和残留定时器。

## 验证

- 93 项测试通过，新增工作区、负坐标、小屏幕、底边展开、配置迁移／保存和快捷键消息排队检查。
- `scripts/dock_probe.py` 使用真实 Tk／Win32 窗口和物理鼠标点击，验证左右边缘、主条收起按钮、箭头展开、拖动和重启恢复。
- 测试窗口独占注册 `Ctrl+Alt+F11`，实际生成组合键开始模拟录音，并向自有窗口发送快捷键消息停止；没有向其他应用写入文字。
- 验证收起不误开始／停止、不换任务、不抢焦点；预览更新不重新显示，展开恢复最新预览；隐藏状态的错误不弹窗。
- 原有 4 个屏幕位置的预览开始／停止点击回归通过。

报告及截图位于忽略目录 `data/dock-test/`。测试使用模拟任务，不开麦克风、不加载模型、不调用 ASR，不代表语音精度或识别速度验收。
