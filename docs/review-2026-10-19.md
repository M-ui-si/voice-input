## 已修复

| 问题 | 修正 |
| --- | --- |
| 实时分段把重叠部分计入 8 秒间隔，实际新录音只有约 6 秒 | 按新增 PCM 计时；首段 8 秒，后续窗口为 8 秒新录音加 2 秒重叠 |
| 旧测试仍要求 60 秒实时分段、允许单字纠错 | 更新回归，并重建 PCM 检查分段没有丢失或重复 |
| 重试成功只清理新分段，可能留下失败任务的分段录音 | 重试接管旧分段的清理责任，成功和取消都覆盖 |
| 同一任务的重复终结事件可能再次消费 | 每个任务只接受一次结果/错误，后续旧事件丢弃 |
| 快速连续粘贴可能把上一次转写当作原剪贴板 | 复用原始剪贴板快照；退出时执行未完成恢复；保留用户新复制内容 |
| 英文纠错可能改写较大单词的内部片段 | 加入 ASCII 单词边界；保持单遍替换和单字规则拦截 |
| 空或异常设置值可能使界面报错或启用未知模式 | 按字段验证，非法值回落到默认值 |
| 词表完整传入模型曾造成词表回显 | 继续禁用整张词表 decoder context；个人术语保留，但不声称能引导本地模型 |
| 空文本框/浏览器 UIA TextPattern 可能不可读 | 优先读取可写 ValuePattern；不可确认的文档拒绝自动粘贴 |
| 旧错误窗口可能对新任务执行重试/取消 | 按显示时的任务编号校验 |
| 准备模型可能与推理同时写入运行库；损坏下载片段会被不断复用 | 任务忙时拒绝准备/导入；SHA-256 失败后清除对应缓存片段 |
| 测试配置和实际用户配置共享单实例锁 | 单实例锁增加数据目录指纹，独立测试不会唤起实际用户窗口 |
| Windows PowerShell 5 错读无 BOM 的 UTF-8 构建脚本 | 构建脚本改为带 BOM 的 UTF-8 |
| 设置页新增内容后底部按钮被挤压 | 增加设置窗口高度并提前预留底部按钮区域，打包截图复核完整可见 |
