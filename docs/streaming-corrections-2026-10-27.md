# 纠错积累、云端分段与暂停续录

日期：2026-10-27。范围为用户确认的全局纠错积累、云端约 8 秒新音频分段、累计预览和云端／本地暂停续录。

## 实现

- 历史增加可空修改稿与边界检查信息，启动时幂等升级；当时生成的原文不重写。修改记录仍按原创建时间保留 7 天。
- 保存修改与确认纠错分开。候选默认不勾选，可调整词对；只生成替换候选。规则使用三方合并，保护较旧设置窗口之外的新规则或用户决定。
- 录音器共用样本精确切片：8 秒新 PCM、最多 2 秒重叠；始终保存完整录音。暂停停止采集、排空队列、提交尾段，继续后重置重叠并保留同一任务和目标。
- 云端单任务串行识别片段，累计原始文本单独合并，展示和最终输出使用任务启动时的规则快照。不确定边界保留两侧文字，并将检查信息保存在历史。
- 暂停期间仍可接收已提交片段的预览。录音计时仅统计已采集样本；主快捷键在暂停态仍表示结束。
- 云端持续失败后停止后续请求，但继续录音；结束后进入重试界面。重试云端重新切分完整 WAV，本地恢复仍走原有分段。取消后的迟到结果不得写历史或填入。
- 设置新增 `cloud_segmented`，旧配置默认启用，用户可切回停止后整段识别。

## 真实云端与速度限制

- 已生成固定 Windows SAPI 中文样本，时长 60／180／300 秒，不包含私人录音或历史文字。
- 首个 60 秒整段基线请求返回 HTTP 402，程序按现有额度／免费服务保护停止，未反复请求、未切换模型。因此本轮尚未取得真实分段返回结果，也没有真实速度比较结论。
- 评估脚本新增 `--cloud-strategy whole|segmented|compare`。分段按实际录音速度释放片段，记录首次预览、停止后等待、请求次数、错误率及边界检查信息；服务错误会落盘记录并停止整组，不继续消耗请求。
- 缺少真人录音与人工参考原文；自动化、合成语音和麦克风采集检查均不能替代真人准确率验收。本地实际模型暂停前后识别效果亦待真人验证。
