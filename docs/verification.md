## 可复现检查

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\build.ps1
.\.venv\Scripts\python.exe scripts\package_probe.py
```

`package_probe.py` 在独立本地数据目录打开打包版设置，检查截图、回调错误、实际内存、子进程及退出状态；不会使用麦克风或上传录音。

真人评估清单见 `docs/acceptance.example.json`。示例没有配套音频，不是已完成的验收样本。调优样本与验收样本应分别维护；评估脚本的关键词存在率不能代替数字、否定词和完整语义的人工检查。当前总耗时统计包含首次模型加载，不应直接当作“停止录音后延迟”。

本地采用私有进程管道而非 HTTP 回环服务，未开放网络监听端口。下载完成不会自动加载模型。云端失败后保留录音并由用户选择识别路径。

## 实时预览改动

2026-10-19：本地录音在录制期间约每 8 秒产生一个识别窗口，窗口之间重叠 2 秒；识别到的累计文字显示在置顶、不抢焦点的旁侧预览窗。最终识别完成后沿用原来的目标位置检查，再一次性填入；预览内容不会自动插入或发送。云端接口仍是整段上传并返回完整文字，云端模式不反复上传音频，也不加载本地模型，因此没有边录边显字。

此改动尚未用真实麦克风与本地权重完成实时延迟和准确率测量。分段频率是设计值，不是性能保证。历史 34 项测试不包含本次实时预览改动。

## 术语表回显与插入光标修正

2026-10-19：最近的本地历史记录包含多条几乎覆盖整张术语表的结果；设置同时存在 `n=notion` 单字替换规则。前者由本地识别把整张个人术语表作为 decoder context 导致，现改为不传术语上下文；后者会全局替换文本中的每个小写 `n`，现保存时拒绝单字符错词，并在替换函数中忽略旧有单字符规则。个人术语仍保存在设置中，但目前不用于本地 decoder 引导，避免再将词表回显；本地技术词准确率需后续真人录音验证。

插入校验现允许录音期间在同一控件内移动光标或选择文字；只要目标窗口、控件和文档内容仍一致，完成时按当前光标／选区插入。切换控件或文档内容发生变化时仍拒绝自动插入。此修正尚未通过真实 Agent 页面和中文输入法实测。

本次修改后 `compileall` 成功，PyInstaller 新目录构建成功，打包版设置窗口已启动。没有运行测试套件，也没有进行麦克风识别、光标移动或真实 Agent 页面的实测。旧历史记录保留原样，不会被新逻辑追溯改写。

## 密钥保存提示修正
